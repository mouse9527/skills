# 外卖（手机）

先遵守「手机通用规则」（硬规则：**只做到提交订单前**，截图交用户付款）；价格判断（神券价、满减、会员价）按「购物通用」。这里是外卖和即时零售的共性方向。

## 选平台

| 用户要 | 通常去 | skill |
|---|---|---|
| 外卖（默认） | 美团 App 里的外卖（独立「美团外卖」App 如果装了也可以） | 「美团外卖」 |
| 超市 / 生鲜送到家（美团系） | 美团 App 里的小象超市 | 「美团小象超市」 |
| 淘宝闪购 / 饿了么 | 淘宝 App 首页「闪购」 | 「淘宝闪购」 |
| 京东秒送 / 京东外卖 / 超市秒送 | 京东 App「秒送」 | 「京东秒送」 |

用户没指定平台时默认美团；用户说「比价」或「哪家便宜」才多家都看。手机上装了哪些 App 以手机服务列出的已装 App 为准。

## 先问清楚（能一句话问完就一句话）

- 吃什么 / 哪家店 / 买什么；几份、规格、忌口——没说就按默认规格，结算前再让用户改
- **送到哪**：配送费、能不能送都由 App 里选中的收货地址（页面顶部那行）决定。**先分场景**（只写在「用户位置」skill 第 5 节）：**外卖**按用户所在位置，当前地址不在附近就从已保存地址里切到近的；**买菜 / 生鲜 / 超市到家**先列已保存地址问用户送哪个（只查价、地址不影响结论时可以不问，说明按哪个地址查的）；买药 / 便利店看是不是马上要送到用户身边。用户这一轮说了地址就直接用
- 比价时**每个平台都要对齐**到同一片地址（尽量是同一个已保存地址），否则配送费、距离、能不能送都没法比

## 常见任务的方向

- **看菜单 / 配送费**：在平台的外卖页搜店名或品类 → 从结果读店铺卡（评分、月售、起送、配送费、送达时间、距离）→ 进店读菜单。**只看的任务不加购**
- **下单（备好给用户付）**：加购时规格没说选默认；加完去结算页，**在结算页停**，读出商品 × 数量、小计、包装费、配送费、优惠、实付、地址、预计送达，截图交用户
- **比价**：同一家店（或同类）在各平台看**实付**（小计 + 配送费 + 包装费 − 当前可用优惠），菜单价不准；比价时每家只看不加购；用户选定后再在那家备好。多家都看耗时长，先跟用户说一声

## 风险与坑（通用）

- 红包、会员、「免配送费」、外卖券弹层：关掉，不领、不开通
- 店铺「休息中」「超出配送范围」：换下一家，告诉用户
- 搜索结果里可能混着「只到店自取」的同名店：不能外送，要说明
- 购物车里有用户以前加的东西：不删，结算前告诉用户
- 结算页的「用红包 / 开会员省 X 元」：保持原样，告诉用户有这个选项

## 结果怎么给

一张小表：平台 | 店 | 起送 | 配送费 | 送达 | 实付或菜单价（注明）| 备注。只看菜单时列出用户关心的几样菜和价格，说明价格口径（如「神券价」）。
