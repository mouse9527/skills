# 拼多多（手机 App）

先遵守「手机通用规则」；比价、到手价和正品判断按「购物通用」。这里是拼多多 App 的方向和参考，界面以当时为准。

## 只做只读比价（Owner 2026-10-21 定）

拼多多只接「看价格、比价格」。以下一律不做，用户要求也只说明「这一步请你自己在拼多多里操作」：

- **不拼单、不单独购买、不下单**：底栏主按钮上直接写着价格（「免拼购买」「发起拼单」「立即参与万人团 ¥X」「秒杀价 券后¥X」），**看价格读元素，不要点它**；页面中部的「立即拼单」（参加别人的团）也不点
- **不点「先用后付」「支持 0 元下单」**（这就是下单）
- **不领券、不抢券**（「立享9.5折」「抢券」「先领券 再下单」「点击立抢」）
- 不收藏、不关注店铺、不联系客服；分享只用来**取商品链接**：点「分享」→ 面板里只点「复制链接」（见下面「商品链接」）。「分享到拼小圈」「买一件送给好友」和面板里的其它项都不点
- 社交裂变功能不接：拼小圈、砍价、助力、免费领水果、免费领礼物、省钱月卡、充值中心
- 不登录（参考 2026-10-21：手机上的拼多多是已登录状态）；不授予任何权限

## 入口与定位

- 包名 `com.xunmeng.pinduoduo`，用手机服务启动
- 参考 2026-10-21 实测：冷启动没有开屏 / 弹窗 / 验证，直接到首页；首页、搜索页、结果页、详情页、个人中心**元素都读得到**（约 130–175 行，1–3 秒），通常不用截图

## 常见任务

- **搜索**：点首页顶部搜索框（占位词是推荐词）→ 输入（关键词带中文，读 EditText 核对）→ 点「搜索」。**输入框没有清空按钮**，旧词用 `BACKSPACE` 删干净再输入
- **结果页**：卡片能读到完整标题（含【海外版】【需要当面签收验货】「二手」等）、价格标签（「抢券后¥X」「券后¥X」「秒杀价¥X」「¥X」）、「本店已拼 N 件」「N 万人收藏」「限购1件」「顺丰包邮」「广告」；排序：综合 / 销量 / 价格 / 品牌 / 筛选
- **详情页**：价格栏是一个 ViewGroup，**读它的 label 一次就全**（参考：「优惠前¥1898¥131914:00抢券后¥1219总售2.2万+件·快要抢光」）；还能读到保障（退货包运费 / 7天无理由 / 正品发票 / 假一赔十 / 正品险）、评价数和评价总结、店铺（「3年老店」「全店总售」「近30天已拼」）、底栏价格
- 看完 BACK 回结果页，不从首页重搜

## 哪个价格算数（拼多多特别乱）

**主价报详情页底栏「单独购买 / 免拼购买」的价格**——这是不拼团、不领券现在就能付的价。其它价格分开列，写清条件：

| 看到的 | 一般含义 | 怎么报 |
|---|---|---|
| 结果卡「抢券后¥X」 | 要先抢 / 领券；常和详情页能付的价差很大（参考 2026-10-21：卡片「抢券后¥1269」，详情页底栏「¥2100 免拼购买」） | **不当主价**，进详情页核对 |
| 「14:00 抢券后¥X」 | 定时开抢的券，**还没开始** | 写明开始时间 |
| 「拼单价」「发起拼单 ¥X」「立即参与万人团 ¥X」 | 要拼团 / 参团 | 单列，说明要拼团 |
| 「百亿补贴」「秒杀价」「限时秒杀」 | 平台补贴 / 限时活动，常限购 1 件 | 单列，写限购和时间 |
| 「优惠前¥X」 | 参照价 | 只作对比 |

拿不准就截图给用户看价格栏。最终以结算页为准，你不进结算页。

## 正品与渠道

按「购物通用」的「辨别正品 / 国行」：【海外版】、全球购、二手单独列，不和国行价放一起比；「假一赔十」「正品险」只保证不是假货，不等于国行保修。

## 收尾

- 任务结束按 HOME 回桌面（别停在详情页，免得下次热启动落在旧页面）
- 参考 2026-10-21 实测：拼多多打开过一次后，进程和 4 个服务会一直留在后台。用户问起时如实说明

## 商品链接

最终回复给商品链接按「购物通用」的「给用户商品链接」：**默认分享 → 复制链接拿 `mobile.yangkeduo.com/goods….html?ps=` 直达链接**，目标是**拿到正确的链接**（Owner 2026-10-22：多截图没关系，保证拿对）；试满 3 次拿不到才退回搜索链接并注明（`https://mobile.yangkeduo.com/search_result.html?search_key=<URL 编码的关键词>`）。拼多多这边的参考（2026-10-22 实测，界面以当时为准）：

- **拼多多的元素编号特别不稳**：详情页有「直接拼成」倒计时轮播，同一页 10 秒内「分享」按钮的 ref 在 @e156 / @e164 / @e172 之间跳；面板里按 ref 点「复制链接」实测点到了「分享图片」。所以**这里一律按坐标点**（用元素的 `at` / `size` 算中心，或截图换算，按坐标点击传 `x` / `y`），不按 ref
- **分享按钮**：详情页右上角，**有两个紧挨着的按钮**——左边「分享到拼小圈」（x≈933–1053，**不点**，会发到拼小圈），右边「分享」（中心约 `c=1125,202`）。读元素找 label 正好是「分享」的那一项，按它的坐标点
- **分享面板**（元素读得到）：一排五项 **微信 / 复制链接 / 分享图片 / 朋友圈 / QQ好友** + 底部「取消」，没有联系人。坐标参考（1200×2670）：「复制链接」图标中心约 `c=372,2252`，文字在它下面 y≈2345–2397；**右邻「分享图片」**图标中心约 (612, 2252)，左邻「微信」约 (132, 2252)，间距约 240
- 做法：点「分享」→ **等 1–2 秒面板停稳** → 截图核对「复制链接」位置 → 一次批量执行「按坐标点『复制链接』→ 取前台 App（间隔）→ 读剪贴板」（**不加 BACK**：点对了面板自动关，再 BACK 会退出详情页）。第一件成功后记下坐标，后面几件复用（仍先截图核对）。剪贴板应是 `https://mobile.yangkeduo.com/goods.html?ps=<分享码>`（参考 2026-10-22 也出现过 `goods2.html?ps=`，同样算对），且和上一次读到的不一样（一样 = 没复制上）（拼多多没有标题，靠「刚从这件的详情页点出来 + 和上一条不同」确认）
- 没拿到：剪贴板是空的 / 没变 → 面板若还在就按 BACK 关；若弹了「图片已生成并保存在手机相册 / 你也可以现在分享给微信好友」（点到了「分享图片」）→ **不点「分享给微信好友」**，BACK 关掉，回详情页重新点分享再来。生成的海报存在 `相册 / Pindd`，在回复里提一句
- 点对了面板**自动关**
