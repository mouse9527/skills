# 京东（手机 App）

先遵守「手机通用规则」；比价和到手价判断按「购物通用」。这里是京东 App 的方向和参考，界面以当时为准。

## 适用场景

京东商品搜索、比价、看详情 / 评价 / 价保、看购物车；用户明确要求时加购。

## 入口与定位

- 包名 `com.jingdong.app.mall`
- 首页顶部是搜索框；顶部「秒送」tab 和首页的「外卖 / 秒送」入口是即时零售（看「京东秒送」）

## 怎么看界面

- **先读元素**（「手机通用规则」第 4 节）。参考 2026-10-20 mobile-mcp 实测：首页、搜索页、结果页、商品页、秒送页都能读到，结果卡片的 label 里就有「标题 价格,到手价,原价 送达 销量 好评率」，商品页有「政府补贴价」「已选：规格，数量」和底栏按钮。**购物车读不到**商品和价格（只有数量框）——看购物车要截图
- 搜索页输入后**按回车可能不提交**（参考：停在联想词列表），通常要点输入框右侧的「搜索」按钮
- 搜索页有一个「智能模式」开关（京东的 AI 购物模式），不用动它
- 热启动会停在上次的 tab（参考：停在「秒送」），先回「首页」再搜
- 输入关键词按「手机通用规则」第 6 节（带中文、输完读输入框核对）；搜索页的输入框是 `EditText`，元素里能看到当前文字
- 结果页留意搜索范围：参考实测默认落在「**搜新品**」范围，会漏掉在售商品，切回普通搜索

## 常见任务

- **搜索 / 比价**：结果页通常有 tab（全部 / 秒送 / 店铺 / 口碑）、排序（综合推荐 / 销量）、筛选，以及快捷条件（京东物流 / 国家补贴 / 今日达 / 二手）。要「自营」「正品」优先看带「自营」标的或官方旗舰店
- **卡片上的价格**：参考有「到手价」「政府补贴价」两种写法，旁边的划线价是参照；以商品页为准
- **看商品页**：参考同屏有「政府补贴价·全网低价」、国补比例（常附「仅部分地区可享」小字）、PLUS 专享券、「京东支付已减 X」、「已享受：限 N 件特惠」、价保天数、「已选：规格，数量」。**购买按钮上的价格可能以京东支付 / 白条为条件**——报价时说明
- **看购物车**：可从商品页底部「购物车」或首页底部进入。按店铺分组，有规格、数量、价保、「比加购降 X」；勾选和数量**不动**
- **收货地址**：网购按「用户位置」skill 第 5 节 B——要加购 / 下单、或地址影响结论（运费、能不能发、国补地区）时，先读已保存地址列表问用户寄到哪个；只查价、比价时按 App 当前地址，回复里说明用的是哪个（参考：商品页「送至 <地址>」那一行，点开就是地址列表；未实测）

## 要读出的信息

商品名 + 规格、自营 / 旗舰店 / 全球购、到手价及条件（国补、PLUS、支付方式）、好评率、已售、送达（明日达 / 京东物流）、价保、售后。

## 风险与坑

- **结果页每张卡片右侧常有「+」，那是加购**：点卡片看详情时点标题或图片，离「+」远一点
- 购物车里可能已有勾选的商品（参考实测：有一件本来就勾选着）——不改勾选；合计金额不代表用户这次要买的
- 国补 / 政府补贴有地区和资格限制，不要说成人人可享
- 浮窗（直播讲解、领券弹层）关掉即可，不领
- 验证码按「手机通用规则」；登录失效交给用户

## 停在哪

默认看完给比价结果就停，不加购。用户要加购：加完说明，**不点「去结算」「立即购买」/ 购买按钮**。

## 商品链接

最终回复给商品链接按「购物通用」的「给用户商品链接」：**默认分享 → 复制链接拿 `3.cn` 直达短链**，拿不到退回搜索链接并注明。京东这边的参考（2026-10-22 实测，界面以当时为准）：

- **分享按钮**：详情页右上角，元素 label「分享」（按它的 at/size 算中心点坐标点，不按 ref）
- **分享面板**（ShareActivity）这次元素读得到（2026-10-21 时读不到；读不到就截图后按坐标点）：「分享到」+ 右上「关闭」、「分享好友领福袋，最高可得8.8元红包 / 去看看」（不点）、第一排 **微信好友 / QQ好友 / 小红书 / 朋友圈 / QQ空间 / 新浪微博**、第二排 **复制链接** / 生成海报。**没有联系人列表**
  - 坐标参考（1200×2670 屏幕，以当时为准）：「复制链接」是第二排**最左边**那一项，元素 `at=69,2263 size=189x295` → 中心约 (163, 2410)；右邻「生成海报」x≈280–469，正上方是「微信好友」。按「购物通用」：等面板停稳、截图核对后按坐标点击（传 `x` / `y`），不按 ref
- 点完面板**自动关**，回到详情页；**一定读剪贴板确认**是这件的 `3.cn` 链接（和上一条相同 = 没复制上），没拿到就重新点分享再来（同一件最多 3 次）
- 剪贴板：`【京东】https://3.cn/<短码>?jkl=<token> <口令> 「<标题>」 点击链接直接打开 或者复制文案打开京东`——只贴 `https://3.cn/…?jkl=…`（token 里可能带 `@`，到空格为止都是 URL）
