# 淘宝闪购（手机）

先遵守「手机通用规则」；外卖的共性（问清楚、收货地址、比价、停在哪）在「外卖（手机）」；价格判断在「购物通用」。这里是淘宝闪购的方向和参考。

## 入口与定位

- 在淘宝 App（`com.taobao.taobao`）里：首页**顶部 tab「闪购」**（参考：带「外卖」角标，在「推荐」右边）。饿了么独立 App（`me.ele`）如果手机上装了也可以用，实测手机上没装
- 淘宝热启动会回到上次的 tab，先回首页再进闪购；冷启动的大弹窗关掉，不点「领」
- 闪购页参考 2026-10-20 mobile-mcp 实测：顶部 tab、搜索栏、底栏能读到，**店铺列表读不到**——列表要截图；进店之后未测

## 页面参考（2026-10-20 实测，可能改版）

- 闪购页顶部有搜索框（左侧有「闪购▾」范围），下面一行是**收货地址**

## 切收货地址（参考 2026-10-21 实测）

- 入口：闪购页 / 闪购搜索结果页顶部右侧的「📍 <地址>」→「选择收货地址」页（元素读不到，要截图；点偏了没反应就再点一次）
- 结构：城市 +「请输入地址」搜索框；「当前定位 / 重新定位」；**「闪购收货地址」**＝已保存的地址（勾选的是当前，标签「家 / 公司」「距离最近」，每条「置顶 / 编辑」）；**「附近地址」**＝按手机定位列的周边 POI；底部「使用淘宝地址」「新增收货地址」
- 选择：在「闪购收货地址」里点那条地址的文字（2026-10-21 回归里模型这样切成功），回到页面读顶部地址核对
- 用哪个地址分场景（「用户位置」skill 第 5 节）：闪购外卖按用户所在位置，闪购超市 / 买菜问用户送哪个
- **「距离最近」「当前定位」「附近地址」都是按手机定位算的**（手机在家），不代表离用户近——距离按「用户位置」skill 第 5 节自己算
- **不点**：「附近地址」里的条目（会用一个未保存的地址）、「重新定位」、「置顶」「编辑」、「新增收货地址」、搜索框里输地址
- 频道：美食外卖 / 超市便利 / 看病买药 / 盒马鲜生 / 到店团购 / 午餐 / 甜品饮品 / 天猫超市 / 淘宝便利店…
- 列表上方有排序 / 筛选（满减、30 分钟、距离最近、筛选）
- 店铺卡上有月售、起送、配送费（或免配送费）、评分、送达时间

## 常见任务

- **看某家店的菜单 / 配送费**：闪购页搜索框搜店名（或品类），从结果进店；店铺卡和店内都能读到起送 / 配送费
- **超市 / 便利 / 买药**：从对应频道进，思路同外卖（看商品、价格、配送）
- **比价**：按「外卖（手机）」，同一家店在各平台看到结算前一步的实付

## 风险与坑

- 底部常有「红包待使用」「吃货卡」提示，不点「去使用」（除非用户要求）
- 价格有满减、红包、会员的条件价，按「购物通用」说明条件
- 到店团购在闪购里也有，用户要团购时说明是哪个平台的团购

## 停在哪

只看菜单的任务不加购。用户要下单：最多加购到结算页，读出明细，截图交用户。
