# 微博（手机 App）

先遵守「手机通用规则」（硬规则、怎么看界面、输入核对、一口气做完再回复）。这里是微博 App 的方向和参考，界面以当时为准。

## 只读（Owner 2026-10-21 定）

以下一律不做。**用户明确要求也先不做**（「帮我关注 X」「帮我点个赞」「帮我转发」）：回复「微博这边目前只读，这一步请你自己在微博里操作」——以后要不要放开由 Owner 决定。

- 发微博、转发、评论、点赞、收藏
- 关注 / 取消关注、私信、加入粉丝群、超话签到、投票、打赏 / 赞赏
- 分享（分享面板、微信 / 朋友圈 / QQ 按钮，常标「领红包」）
- 举报、「不感兴趣」/ 屏蔽（会改推荐）、修改资料、打开或关闭任何设置
- 签到条「领取」、活动横幅「去参与」、浮动广告
- 不登录、不升级 App、不授予任何权限

## 适用场景

- 「微博热搜是什么」「热搜第一是什么事」
- 「微博上大家对 X 怎么看」「X 话题最新进展」
- 「某某（博主 / 官方号）最近发了什么」
- 「这条微博评论区怎么说」

小红书笔记用「小红书」skill（专用工具），不是这里。微博**用手机 App**，不用浏览器工具打开 weibo.com（网页要登录的地方多，且手机里已登录）。

## 入口与定位

- 包名 `com.sina.weibo`，用手机服务启动。参考 2026-10-21 实测：已登录；冷启动有时有开屏广告（右下「跳过」），没有授权弹窗
- **热启动会回到上次停留的页面**（别的对话留下的搜索页、话题页、热搜榜），按 BACK 退回时一路都是旧页面
- 底栏「首页 / 视频 / 发现 / 消息 / 我」。**首页信息流一直在刷新**：读完元素过几秒再按旧 ref 点，可能点到一条微博上（实测）——底栏 tab 用坐标点，或读完立刻点
- **「发现」页读元素会失败**（界面树太大，mobilecli 报 `ENOBUFS`）：直接截图。顶部「微博热搜」预览 +「更多热搜 >」

## 常见任务

### 热搜
- 发现页点「更多热搜 >」进热搜榜。**默认停在「我的」tab（个性化）**，公共榜要切到「热搜」tab（另有 科技 / 社会 / 文娱 / 生活 / 同城 / 体育）
- **热搜榜页不会自己刷新**：如果是 BACK 退回到的、或热启动就停在热搜榜，那是旧榜（参考 2026-10-21 回归：模型 BACK 回到 33 分钟前打开的榜，当成现在的报了）。先在榜单顶部**下拉刷新一次**（从列表上部往下滑），或从「发现」重新点「更多热搜 >」；回复里写「约 HH:MM 的榜」。拿不准就在 App 里再刷新一次，不要换浏览器去网页对照
- 读元素能拿到**词条 + 热度数字**（有的带「综艺」等类别）；**排名数字和「新 / 热 / 爆 / 上新 / 官宣 / 辟谣」标签是图片**，要的话截图一次
- **没有热度数字的行是置顶或推广位**（参考：置顶的宣传词条、标「上新」「官宣」的品牌词条），报「前 10」时不算进排名，单独说明有推广位
- 点词条进话题页

### 话题页 / 搜索
- 话题页能读：话题名、阅读量 / 讨论量、「主持人：X | N家媒体发布」、事件导语、置顶微博正文、「N人正在讨论」「X%用户认为"…"」立场条；「热搜TOP 1」这类标签、作者名在元素里是乱码或缺失（`*&**&*`），要看就截图
- tab：综合 / 智搜 / 实时 / 视频 / 图片 / 用户 / 关注。**「实时」= 按时间 / 最新互动排的最新微博**，「综合」= 平台挑的热门。问「最新进展」看实时，问「大家怎么看」两个都看
- 搜关键词：点顶部搜索框（或话题页标题）进搜索中间页，输入框**没有清空按钮**，旧词用 `BACKSPACE` 删；关键词带中文，读 `et_input` 核对；点「搜索」或 ENTER
- 「微博智搜 · 快速回答（AI生成）」卡片是 AI 汇总，**不当事实来源**

### 看博主
- 搜名字，综合 tab 的**用户卡**（名字、认证、粉丝数）点进主页；或切「用户」tab
- 主页能读：粉丝 / 关注 / 转评赞、认证文字、「昨日发博 N」、最近微博正文；tab「精选 / 微博 / 视频 / 文章 / 相册」，最新微博看「微博」tab
- **「置顶」标、V 认证徽章是图片**：第一条可能是置顶（时间往往较早），截图确认；报「最近发了什么」时跳过置顶或注明
- 同名 / 山寨号多：看认证文字（「XX法人微博」「XX官方微博」）和粉丝量

### 单条微博和评论
- 点**正文文字区域**进「微博正文」：避开图片（会进图片预览）、#话题# 链接、下面的转发 / 评论 / 赞按钮
- 能读：正文全文、引用卡片、转发 / 评论 / 赞数、评论（昵称、内容、时间、「来自 X」IP 属地）。**作者名和「发布于 X」元素里没有**，需要时截图
- 要看图里的内容才截图

## 怎么判断内容（方向）

- **事实 vs 说法**：评论区和普通用户的说法不是事实；有官方 / 媒体发布的（话题页「N家媒体发布」、认证机构号）优先，**引用时写清是谁、什么时间发的**
- 未经证实的爆料、截图转述：标注「未经证实」；热搜榜的「辟谣」标签、官方通报要提
- 营销号：没认证或认证是「博主 / 自媒体」、标题党、带货链接——作为参考，不当来源
- 关键词搜索结果会混进**别人提到这个词的微博**（参考：搜「人民日报」，结果里有普通用户的讽刺帖），不要当成那个账号自己发的
- 「有代表性的几条」：不同立场各取一两条，写明立场条（「X%用户认为…」）是平台统计、不是民调

## 隐私

不把用户自己的微博账号信息、关注列表、消息 / 私信内容、首页推荐带进回复，除非用户问到。

## 给链接

按「购物通用」的思路：能可靠拿到才给，**不编造微博 / 用户 id**。参考 2026-10-21 实测（浏览器未登录微博）：
- 热搜榜 `https://s.weibo.com/top/summary` —— 访客能看完整榜（含排名和标签）
- 用户主页 `https://weibo.com/n/<昵称>` —— 能看资料，微博列表要登录
- 搜索 / 话题 `https://s.weibo.com/weibo?q=<词>` —— 要登录，链接后加一句「或在微博 App 里搜『<词>』」
- 单条微博：App 里读不到微博 id，不给链接，写「在 <博主> 主页 / <话题> 实时里，<时间> 那条」
