# 闲鱼（手机 App）

先遵守「手机通用规则」（硬规则、怎么看界面、输入核对、一口气做完再回复）；价格判断和正品 / 国行识别按「购物通用」。这里是闲鱼的方向和参考，界面以当时为准。

## 硬规则（Owner 定，闲鱼专属）

只读浏览。以下一律不做，用户要求也只说明「这一步请你自己在手机上操作」：

- **不给卖家发消息**：不点「聊一聊」「留言」，不回复任何人
- **不出价、不砍价**（「出价」「议价」「蹲降价」都不点）
- **不点「我想要」「立即购买」**，不下单、不付款
- **不收藏**（详情页底部「收藏」，常显示为一个数字）、不关注卖家
- **不登录**；遇到登录 / 实名 / 人脸，停下交给用户

## 适用场景

- 「XX 二手大概什么价」「闲鱼上挑几个靠谱的」「这个闲置值不值」
- 想买二手 / 闲置、或用户想对比全新和二手

## 入口与定位

- 包名 `com.taobao.idlefish`，用手机服务启动
- 参考 2026-10-21 实测：冷启动有时有开屏广告（右上角「跳过广告」，点它即可），无验证，然后到首页。首页顶部 tab「首页 / 集市 / 圈子 / 回收」，下面是搜索框（占位词是推荐词，不是用户输入的）、频道（手机数码 / 二手车 / 上门回收…）、瀑布流推荐
- 底栏「卖闲置」是发布，不点

## 怎么看界面（参考 2026-10-21 实测）

- **元素基本都读得到**：首页、搜索页、结果页、详情页 `list_elements` 都能拿到文字，比截图快
- **搜索框要点两次才跳**：第一次点首页搜索框可能没反应，再点一次进搜索页（有「历史搜索」「猜你可能在找」）
- **输入**：纯英文会被输入法打乱（实测「AirPods Pro 3」进框变成乱码）；带中文的关键词用剪贴板粘贴时**闲鱼搜索框不接**，框还是空的 → 按「手机通用规则」第 6 节，用键盘剪贴板面板插入，读元素核对 `EditText` 里的字
- **结果页**：每张卡读得到 标题（卖家描述开头）、成色 | 品牌 | 款式（如「几乎全新|Apple/苹果|入耳式」）、价格、参照价（「¥1899已售65」「已降1397元69人想要」）、包邮 / 免息 / 「描述不符包邮退」、地区、「回复超快」等标签。顶部 tab「全部 / AI智搜 / 个人闲置 / 回收 / 用户」，排序「综合 / 价格 / 降价 / 新发 / 区域 / 筛选」，快捷筛选「个人闲置 / 鱼小铺 / 3期0息 / 验货宝 / 成色 / 品牌」
- **详情页**：顶部卖家昵称 +「刚刚擦亮 | <城市>」；价格栏 label 一次给全（「¥720，活动价，成色，包邮，最高享3期免息，330人想要，7495人浏览」）；描述全文；规格（品牌 / 型号 / 成色 / 款式 / 功能状态）；往下滑有「宝贝评价」和**卖家卡**（「来闲鱼4年，共卖出4079件宝贝」「好评率 98%」）。商品图要截图看
- 详情页底栏参考：留言 / 收藏 / 蹲降价 / 立即购买 / 聊一聊——**全部不点**，滑动时注意别误触（从屏幕中部起滑）

## 常见任务

- **二手大概什么价**：搜对型号 → 看结果页一屏或两屏的价格分布，必要时用「价格」排序看低价段是什么。报一个区间，并说清成色、是否个人闲置、是否包邮；离谱的低价单独说
- **挑几个靠谱的**：先在结果页按价格 + 成色 + 地区挑 4–6 条候选，再逐个进详情页看描述和卖家卡，挑出用户要的数量。每条给：价格、成色、卖家类型（个人 / 商家）和信用、保障（验货宝 / 包邮退）、一句话风险
- **和全新比**：全新价按「购物通用」去淘宝 / 京东看（或用结果卡上的参照价，但说明那是卖家 / 平台给的参照）

## 怎么判断二手靠不靠谱（方向）

| 看到的 | 一般意味着 | 怎么跟用户说 |
|---|---|---|
| 卖家卡「来闲鱼 N 年，共卖出 几千件」、昵称像店名（「只做精品性价比」）、标题模板化、「店铺提供 1 年维修」 | **二手商家 / 贩子**，不是个人闲置；有售后承诺但价格通常更高 | 说明是商家，信用好可以考虑 |
| 卖出几十到一两百件、「纯个人闲置」 | 个人卖家 | 看描述和图是否对得上 |
| 价格**明显低于**行情（例如全新 ¥1899、成色「全新未拆封」只卖 ¥280–500） | 高风险：翻新 / 仿品 / 骗局常见特征 | 单独列出、不推荐，除非用验货宝 |
| 标价和正文不一致（实测：标价 ¥502，正文写「爽快的 280 包邮」）、「文案是闲鱼 AI 创作推荐的，所以会出现类似相同的帖子」、多个卖家几乎相同的描述 | 模板化 / 批量帖，可信度低 | 指出不一致，不推荐 |
| 描述里要求加微信 / QQ、「先付款」「走站外」「私下转账」 | **站外交易，骗局高发** | 明确提醒不要这么做 |
| 「验货宝」「描述不符包邮退」「闲鱼交易须知」里的保障 | 平台担保 / 验货 | 作为正面信号 |
| 「几乎全新」「99新」等成色 | 卖家自己选的，**以图为准** | 看图（截图）核对划痕、配件、盒子 |
| 「在保」「可提供购买记录」 | 可核实（序列号查保修、发票） | 提醒用户买前让卖家给序列号自己查——由用户去问，你不发消息 |
| 「已降 X 元」「¥1899」参照价 | 参照，不是成交价 | 只作对比 |

结论通常是：**个人闲置里价格合理、描述和图一致、卖家有一定成交和好评的**排前面；商家货说明是商家；明显低价和不一致的单独列为「不推荐」并说原因。

## 风险与坑

- 搜索框占位词是推荐词：提交前一定读 `EditText` 核对
- 结果卡上的文字是**卖家写的描述**，不是平台核实的信息；「国行」「在保」都要用户自己核实
- 「AI智搜」tab 是 AI 汇总，不是商品列表，挑具体商品用「全部」或「个人闲置」
- 详情页里的商品推荐（「逛了又逛」）不是这次要找的，别混进结果

## 停在哪

只看、只比。用户想买：告诉用户是哪一条（标题开头 + 价格 + 卖家昵称 + 地区），截图交给用户，由用户自己去聊、下单。

## 商品链接

最终回复给商品链接按「购物通用」的「给用户商品链接」：**默认分享 → 复制链接拿 `m.tb.cn` 直达短链**，拿不到退回搜索链接并注明。闲鱼这边的参考（2026-10-22 实测，界面以当时为准）：

- **分享按钮**：详情页右上角，元素 label「分享按钮」
- **分享面板元素读得到**：最上面一排是**最近聊过的真实联系人头像**（label 是昵称，下面写「10-16聊过」之类）——**一点就发给这个人**，而且这排**紧贴在「复制链接」那一排上面**；第二排 **微信 / 复制链接 / 生成分享图 / QQ / 钉钉 / 微博**；第三排 消息 / 举报 / 帮助与客服 / 找相似；底部「取消」
  - 按「购物通用」**按坐标点、不按 ref**（ref 点击时会重新读界面，编号可能偏到联系人上）：坐标用元素 label「复制链接」给的中心点 `c=`，参考中心约 `c=358,1809`；**正上方 y≈1457–1675 是联系人头像**，所以点它的中心或偏下，不要点上沿；点前截图核对，按坐标点击（传 `x` / `y`）
- 点完会弹「**淘口令已复制**」对话框，带「去微信粘贴」「去QQ粘贴」两个按钮——**都不点**，也不点框上的 ×（× 正下面叠着「生成分享图」），**按一次 BACK**，对话框和面板会一起关掉。所以截图核对后一次批量执行「按坐标点『复制链接』→ 取前台 App（间隔）→ 读剪贴板 → BACK」；第一件成功后记下坐标，后面几件复用（仍先截图核对）
- 剪贴板：`【闲鱼】https://m.tb.cn/h.<短码>?tk=<token> <口令> 「快来捡漏【<标题>】」 点击链接直接打开`——只贴 `https://m.tb.cn/…?tk=…`；**一定读剪贴板确认**（和上一条相同 = 没复制上），没拿到就重新点分享再来（同一件最多 3 次）
- 分享链接不等于联系卖家：取链接不违反上面的「不给卖家发消息」，但面板里的联系人、「消息」都不点
