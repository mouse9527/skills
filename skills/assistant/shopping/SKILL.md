# 购物通用

这里是判断方法，不是操作步骤。具体界面以当时看到的为准，App 会改版；下面的「参考」都是 2026-10-20 实测时的样子。

## 目标

帮用户在不下单的前提下，找到合适的商品、讲清楚**真实能付的价格**和差别，让用户自己决定、自己付款。

## 比什么（按用户关心的优先）

- **到手价**（见下一节，最重要）
- 是否同一个东西：型号 / 版本 / 规格 / 数量（「3 代」vs「2 代」、「公开版」vs「官翻」、「1 件」vs「2 件装」）——比价前先对齐
- 卖家类型：自营 / 官方旗舰店 / 授权经销 / 普通店 / 全球购 / 二手，影响正品和售后
- 送达：明日达 / 今日达 / 预售（什么时候发货）、包邮与否
- 售后：7 天无理由、价保（几天）、退货运费险
- 口碑：好评率、评价数、销量（「已售 / x 人付款」）；差评集中在什么

用户只问「哪个便宜」时，先对齐是不是同一个东西再比价；对不齐就说明差别，而不是硬比。

## 哪个价格算数（到手价识别）

国内 App 同一屏常常同时出现好几个价格。通常的判断：

| 看到的 | 一般含义 | 怎么报 |
|---|---|---|
| 「到手价」「券后价」「补贴后」「平台加补后」 | 已经算进当前可用优惠后的价格 | 通常就是要报的价，注明「到手价」 |
| 「政府补贴价」「国补」「领政府补贴省 X」「领取政府补贴 X% 立即领取」 | 国家 / 地方补贴，**常有地区、资格或领取条件**（实测小字写「仅部分地区可享」） | 报出来但说明条件；需要先「领取」的不要替用户领 |
| 「88VIP」「PLUS 专享」「会员价」 | 会员才有 | 说明「会员价」，不确定用户是不是会员就两个都报 |
| 「京东支付 / 白条可享」「XX 支付立减」 | 指定支付方式才有（实测京东购买按钮上的价格就是这种） | 说明支付条件 |
| 「活动补贴后 ¥X · 今晚 8 点开卖」「双11 补贴后」 | **还没开始**的活动价 | 和当前价分开说，告诉用户什么时候生效 |
| 「神券价」「已含券」 | 假设用了平台券（外卖常见） | 说明要用券，以结算页为准 |
| 划线价、「优惠前」「原价」 | 参照价，不是要付的 | 只作对比 |
| 「满 X 减 Y」「多买多返」「x 件 y 折」 | 凑单条件 | 单件买时不算进去，说明凑单能省多少 |

方向：**报「现在、不需要额外条件就能付的价」为主价**，有条件的优惠单独列出并说明条件。拿不准就截图给用户看那一栏。
最终价格以结算页为准；不进结算页时说清「这是商品页展示价，最终以结算为准」。

## 搜专业 / 小众商品

- 先想清楚要的是什么：**品类、关键规格**（例如芯片类型、接口、尺寸、兼容型号）。用户给了照片 / 参数时先从里面读出规格
- 用 2–3 个精准关键词组合（「品类 + 关键规格 + 形态」），比不停换近义词有效
- 结果不对时，先看**是不是同一类东西**（参考 2026-10-20：想找「带芯片的吊坠」，结果大多是「卡套」外壳——品类没对齐，换再多近义词也没用）；对不上就换品类词或加限定词，而不是换说法
- 搜不到符合规格的现成商品，就如实告诉用户，并说明替代方案（服务类商品、别的形态）。不设搜索次数上限，但每一轮都要比上一轮更接近目标

## 辨别正品 / 国行（用户说「注意甄别正品」时尤其要做）

方向：**先弄清「是不是国行正品、有没有国内售后」，再比价**。最便宜的那家常常不是国行。

| 看到的信号 | 一般意味着 | 怎么跟用户说 |
|---|---|---|
| 「自营」（京东自营、天猫超市）、「官方旗舰店」「品牌旗舰店」、「Apple 授权经销商 / 授权专营店」 | 国行、正规发票、国内保修，最稳 | 首选 |
| 「全国联保」「1 年质保」「7 天无理由」「价保」 | 国内售后有保障 | 作为正面信号列出 |
| 「全球购」「海外版」「港版 / 日版 / 美版」「跨境」「天猫国际」「保税仓发货」「进口税已含」 | **跨境 / 非国行**：通常不享受国内官方保修，常不支持 7 天无理由 | 明确标出「非国行」，价格低是因为这个 |
| 「百亿补贴」卡片上标「海外版」 | 补贴的是海外版 | 同上；不要和国行价放在一起比 |
| 「假一赔十」「非正品赔十倍」 | 只保证**不是假货**，**不等于**国行保修或能退换 | 说清这点，别当成国行证据 |
| 第三方「买手店」、标题不规范（堆关键词、品类写错）、型号版本写得含糊 | 渠道和规格都不确定 | 不建议，除非用户只在乎价格 |
| 「二手」「拍拍」「官翻」 | 不是全新 | 单独列，另说 |
| 价格明显低于其它国行渠道（例如低 15% 以上） | 多半是上面的非国行情况之一 | 进商品页核对再下结论 |

用户问「哪边便宜」时，通常两边（淘宝和京东；用户提到拼多多就三家）都看完再下结论，不要只看一家就停（2026-10-20 回归：只看京东就交差，覆盖不全）。
结论通常这样给：**国行正品里最便宜的是哪家（价格和条件）**；非国行的低价单独列出、说明差在哪（保修、退货）；最后给建议。
（依据：2026-10-20 会话，同款 AirPods Pro 3：京东自营 ¥1549 / 政府补贴价 ¥1394.1、天猫授权经销商 ¥1472、天猫国际跨境 ¥1498.6、百亿补贴海外版 ¥1249、全球购买手店 ¥1278——低价的都不是国行。）

## 规格、数量、地址

- 加购 / 下单前确认：规格（颜色、尺码、版本）、数量、是否缺货；用户没说的不要替用户选贵的
- 购物车里**常有用户以前加的东西**，有的已经是勾选状态（实测）：不删、不改勾选、不改数量；需要时告诉用户「购物车里原来还有 X，已勾选」
- 收货地址按「用户位置」skill 第 5 节分场景：**网购（淘宝 / 京东快递）、买菜 / 超市到家**→ 问用户送哪个已保存地址（只查价、地址不影响结论时可以不问，说明按 App 当前地址查的）；**外卖**→ 按用户所在位置。结果页 / 商品页上显示的地址通常就是收货地址，不是用户当前位置。不新增、不编辑地址

## 给用户商品链接（Owner 2026-10-21：「商品最好贴个链接，否则看不到」；2026-10-22：默认用 App 分享出来的直达链接）

最终回复里，**每个商品名都做成 markdown 链接**，让用户在手机上一点就是那件商品。

### 默认：分享 → 复制链接 → 读剪贴板（淘宝 / 京东 / 拼多多 / 闲鱼）

Owner 2026-10-22 定「全放开，默认用」：搜索链接点开还要再找，用户要的是直达那件商品的链接。做法：

1. **看商品时顺手取**（Owner 2026-10-22）：在详情页看一件商品、判断它**可用**（规格 / 价格 / 是否国行等符合用户要求）时，就在这一页**当场**点右上角「分享」→ 复制链接 → 读剪贴板，把这条链接和**这一页读到的信息**（标题、价格、店铺）一起记下。不可用的不取（每取一次都会在平台留一条分享记录）。最后回复只用这些记录，**不再单独回头逐家取链接**
2. 分享面板里**只点「复制链接」**（禁点清单见下）。**分享按钮和面板里的项都按坐标点，不按 ref 点**：
   - 为什么：`@ref` 是「这次读元素时的第几个节点」，点的那一刻工具会**重新读一次界面再按编号找**；页面上有倒计时、轮播、状态栏网速变化时，编号会整体偏几位，同一个 ref 就落到旁边的项上（参考 2026-10-22：拼多多按 ref 点「复制链接」，点下去时编号偏了 4 位，实际点到「分享图片」；同一静止页面 10 秒内「分享」按钮的编号在 @e156 / @e164 / @e172 之间跳）。坐标不受影响
   - 做法：面板弹出后**等一下让它停稳**，再读元素或截图；元素读得到就用「复制链接」那一项（图标或文字）的 `at=x,y size=w×h` 算中心点 `(x + w/2, y + h/2)`；读不到（参考：淘宝）就截图，按截图结果里附带的换算说明算出屏幕坐标。用手机服务按坐标点击，传 `x` / `y`（这是手机屏幕坐标，浏览器的鼠标点不到手机）
   - **点之前截图核对一遍**（多一张截图没关系）：坐标落在「复制链接」图标 / 文字上，不在相邻项（微信、分享图片、保存图片……）或联系人行上
3. **点完读剪贴板**：用手机服务的剪贴板能力读（不带 text）。**和上一条一样 = 没复制成功**（每件的短链都应该不同），按下面「拿不到时」重来
4. **只取 URL**：从剪贴板文字里取出 `https://…` 那一段（到第一个空格为止），**不要**把「【淘宝】大促价保」、口令（如 `HU293`、`CA1565`）、「」里的标题、「点击链接直接打开 或者 淘宝搜索直接打开」这些文案贴给用户。URL 原样用，不改、不删参数（`?tk=` `?jkl=` `?ps=` 是打开商品必需的）
5. 写成 markdown 链接：`[商品名（店铺）](https://e.tb.cn/h.…?tk=…)`
   - **URL 逐字照抄剪贴板读到的原文**：短码和 `tk` / `jkl` / `ps` 都是随机串，错、漏、多一个字符链接就失效（参考 2026-10-22 回归：两条短链各漏了一个字符，点开打不开）。回复写完前，把每条链接和当时读到的剪贴板原文逐字对一遍
6. 关掉面板（有的复制后自动关，有的要 BACK；闲鱼复制后还会弹一个带「去微信粘贴」的框，BACK 关），继续看下一件
7. **全部看完后清剪贴板**：用剪贴板能力写一个空格 `" "`。中途放弃、出错也要清

参考 2026-10-22 实测剪贴板长这样（只取加粗那段）：

| App | 剪贴板内容 | 要贴的 URL |
|---|---|---|
| 淘宝 | `【淘宝】大促价保 https://e.tb.cn/h.<短码>?tk=<token> <口令> 「<标题>」 点击链接直接打开 或者 淘宝搜索直接打开` | **`https://e.tb.cn/h.<短码>?tk=<token>`** |
| 京东 | `【京东】https://3.cn/<短码>?jkl=<token> <口令> 「<标题>」 点击链接直接打开 或者复制文案打开京东` | **`https://3.cn/<短码>?jkl=<token>`**（token 里可能有 `@`，也是 URL 的一部分） |
| 拼多多 | `https://mobile.yangkeduo.com/goods.html?ps=<分享码>`（也见过 `goods2.html?ps=`） | 整条 |
| 闲鱼 | `【闲鱼】https://m.tb.cn/h.<短码>?tk=<token> <口令> 「快来捡漏【<标题>】」 点击链接直接打开` | **`https://m.tb.cn/h.<短码>?tk=<token>`** |

### 分享面板禁点清单（硬规则，Owner 定）

分享面板里**只点「复制链接」**，其余一律不点：

- **联系人**：淘宝「分享给好友」下的每个人和他们右边的「分享」按钮、闲鱼顶上一排「N 天前聊过」的头像——**点一下就直接发给真人**
- 发送 / 分享渠道：微信、微信好友、朋友圈、QQ、QQ好友、QQ空间、支付宝、钉钉、微博 / 新浪微博、小红书、「当面」、「消息」
- 「生成海报」「生成分享图」「保存图片」「分享图片」
- 「分享领红包」「分享好友领福袋」「去看看」，以及复制后弹出的「去微信粘贴」「去QQ粘贴」
- 详情页上的「分享到拼小圈」（拼多多，紧挨着「分享」按钮）

**误点怎么办**（Owner 2026-10-22 定，分两类）：

- **点到联系人 / 任何发送项**（微信、QQ、朋友圈、支付宝、钉钉、微博、小红书、消息、「去微信粘贴」……，哪怕看起来没真发出去）→ **立刻停**，不要再点任何东西去「撤回」，截图告诉用户点到了什么、停在哪一页；这次对话不再用分享面板，剩下的商品给搜索链接
- **点到只在本机生成图片的项**（「分享图片」「生成海报」「生成分享图」「保存图片」——参考 2026-10-22 拼多多：弹「图片已生成并保存在手机相册 / 你也可以现在分享给微信好友」）→ 不算止损：**不点弹窗里的「分享给微信好友」之类的按钮**，按 BACK（或弹窗的关闭）关掉，回到详情页**重新取这件的链接**；在最终回复里提一句「误生成了一张商品海报，存在手机相册里」

### 拿不到时：退回搜索链接，并注明

目标是**拿到正确的直达链接**。没拿到（剪贴板是空的 / 和上一次一样 / 不是 URL / 弹了海报）时：关掉弹窗或面板，回到详情页，**重新点分享、等面板停稳、截图核对、再点「复制链接」**。

这些情况才退回，**这件商品改给搜索链接**，并在链接后写明「（这是搜索链接）」：

- 同一件**试了 3 次**还没拿到
- 面板长得和下面 App skill 写的对不上、找不到「复制链接」，或截图后拿不准坐标（宁可退回，不猜着点）
- 同一 App 连着两件都是试满 3 次没拿到，剩下的也直接给搜索链接

| 平台 | 搜索链接（关键词要 URL 编码，用结果卡上的完整标题，太长就取「品牌 型号 规格」或「店铺名 + 型号」） |
|---|---|
| 淘宝 / 天猫 | `https://s.taobao.com/search?q=<关键词>` |
| 京东 | `https://so.m.jd.com/ware/search.action?keyword=<关键词>` |
| 拼多多 | `https://mobile.yangkeduo.com/search_result.html?search_key=<关键词>` |
| 闲鱼 | `https://www.goofish.com/search?q=<关键词>` |

参考 2026-10-21 实测：没登录的网页里，淘宝搜索链接能直接看到商品；京东、拼多多、闲鱼网页搜索要登录才显示，所以搜索链接后面再写一句「在 App 里搜「<关键词>」也能找到」。这些链接是给用户点的，**不要自己用浏览器打开去核对**（浏览器不是手机，网页要登录还会跳登录页）。

### 其它

- **回复里列出的每个商品都给链接**（不只是推荐的那一两个），用的就是看这件时记下的那条；看过但没写进回复的不用提
- **不编造链接**：只用剪贴板里读到的 URL，或上面的搜索链接；不要从图片、记忆或别处猜 `item.taobao.com/item.htm?id=`、`item.jd.com/<sku>.html` 之类的 id（参考 2026-10-21：四家的元素里都读不到商品 id）
- 分享短链带分享 token，会在平台留下一次分享记录（Owner 已知并接受），不需要向用户解释这一点
- 外卖 / 秒送 / 闪购的店铺：不走分享，写「在 <App> 搜「<店名>」」这样的可复现路径，不给链接

## 停在哪

- 默认只看、只比，不加购。用户明确要加购时才加，并说清加了什么
- **不提交订单、不付款**；不点「立即购买」「领券购买」「去结算」「结算」（硬规则，见「手机通用规则」）
- 不替用户领券、领补贴、开会员

## 给用户的结果

一张小表通常最清楚：商品（含规格）| 店铺类型 | 到手价（注明条件）| 送达 | 售后 | 一句话差别。最后给建议和理由。
