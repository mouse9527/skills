# 美团外卖（手机）

先遵守「手机通用规则」；外卖共性在「外卖（手机）」；美团 App 共性在「美团」。这里是美团外卖的方向和参考。

## 入口与定位

- 通常在美团 App（`com.sankuai.meituan`）里。独立美团外卖 App（`com.sankuai.meituan.takeoutnew`）实测两部手机都没装，装了也可以用
- **不用 deep link**（硬规则：美团系实测 deep link 触发验证码），从首页进
- 两种进法都可以：首页的「外卖」入口；或首页搜索框直接搜「<店名 / 品类>外卖」（参考 2026-10-20 实测：搜「麦当劳外卖」结果直接是外卖店）。首页入口多，误进了别的频道（实测进过「特价团」）就 BACK

## 常见任务

- **看某家店的菜单和配送费**：搜到店 → 结果卡片上通常已有起送 / 配送费 / 送达时间 / 距离 → 进店读菜单（参考：左侧分类、右侧菜品，每个菜有月售、价格、「选套餐 / +」）。只看的任务不点「+ / 选套餐」
- **按品类找附近的店**：搜品类，用排序 / 筛选（距离、评分、起送）缩小范围
- 同名店可能有「只到店取餐」的，不能外送，要分开说

## 要读出的信息

店名、评分、月售、起送、配送费、送达时间、距离；用户关心的菜：名称、规格、价格、是否售罄；店铺满减。

## 风险与坑

- **菜单价格常标「神券价」「已含券」**（实测）：是假设用了美团神券的价，不一定是到手价；按「购物通用」说明，最终以结算为准，不替用户领券
- 外卖的「附近」= 收货地址附近（页面上的地址行），不是用户当前位置；地址不在用户附近时按「用户位置」skill 第 5 节从已保存地址里切
- 会员 / 红包 / 免配送费浮层关掉，不点「领取并开通」

## 停在哪

只看的任务停在店铺菜单页。下单：最多加购到结算页，读明细，截图交用户。
