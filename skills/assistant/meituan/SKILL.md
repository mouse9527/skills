# 美团（手机：到店 / 团购）

先遵守「手机通用规则」；价格判断按「购物通用」。这里是美团 App 的共性和到店团购的方向。

## 美团 App 共性（外卖 / 小象超市 / 到店都适用）

- 包名 `com.sankuai.meituan`
- **不用 deep link**（硬规则），从首页进：首页搜索框，或首页的频道入口（外卖、小象超市、团购…）
- **启动后先看是不是验证页**：美团系冷启动就可能弹验证（参考 2026-10-20：「拖动滑块，刚露出完整的 1 个钥匙就松开」）。按「手机通用规则」自己处理，同一验证最多 3 次
- 首页参考（2026-10-20）：顶部一行是**收货地址**，下面是搜索框；入口有「外卖 / 团购 / 酒店旅行 / 闪购 / 看病买药 / 小象超市 / 美食 / 休闲玩乐…」；底部「推荐 / 小团 / 购物车 / 我的」
- 先读元素：首页、搜索页、搜索结果、外卖店铺页都能读到（参考 2026-10-20 mobile-mcp）；小象超市读不到
- 搜索页输入框旁边的「清除历史记录」是**删搜索历史**，不是清空输入框；输入按「手机通用规则」第 6 节
- 搜索结果有范围 tab「全部 / 外卖 / 团购 / 地点 / 笔记」，要外卖或团购先切 tab
- 首页入口很多，点错进了别的频道就 BACK；首页搜索是全站搜索，关键词里带上意图（「XX 外卖」「XX 团购」）通常更准
- 「小团」「问小团」是美团的 AI 助手，不用它（我们自己操作）
- 热启动会回到上次停留的页面（参考：回到了上一次看的外卖店铺页），先 BACK 回首页再开始
- 美团和点评是一套账号、一套风控：动作放慢，不要短时间重复搜索
- 定位授权弹窗拒绝（位置规则见「用户位置」skill）；会员 / 红包浮层关掉，不领

## 到店 / 团购

- **适用**：用户要团购价、套餐内容、到店优惠；评分和评价更全的在「大众点评」
- **方向**：首页搜「<地标> <店名或品类>」（地标按「用户位置」skill）→ 结果里切到团购 / 到店相关的结果 → 进店看团购区
- **读出**：套餐名、内容、价格、划线价、使用限制（几人用、周末 / 节假日是否可用、是否需预约、有效期）、评分口径（美团分 vs 点评星级）
- **停在哪**：只看。用户要买：选定套餐后最多到提交订单页，截图交用户；不领券、不叠加会员
