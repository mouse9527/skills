# 美团小象超市（手机）

先遵守「手机通用规则」；即时送达的共性（收货地址、比价、停在哪）在「外卖（手机）」；价格判断在「购物通用」；美团 App 共性（不用 deep link、冷启动验证）在「美团」。

## 入口与定位

- 美团 App（`com.sankuai.meituan`）首页的「**小象超市**」入口（参考：带「自营」标；首页还有小象超市卡片「美团自营 · 最快 30 分钟」）
- 进去后是一个独立的商城页（参考：页面顶部写「美团自营」+ 收货地址）
- **这个页面的元素读不出来**（参考 2026-10-20 v3、v4 两次实测：小程序容器，mobile-mcp 也只返回状态栏），以截图为准

## 页面参考（2026-10-20 实测，可能改版）

- 顶部收货地址（标「默认」）、搜索框。小象是买菜 / 超市到家：**先问用户送哪个收货地址**（「用户位置」skill 第 5 节 B），价格、库存、运费会随地址变
- 品类：水果鲜花 / 蔬菜豆制品 / 肉禽蛋 / 海鲜水产 / 乳品烘焙 / 熟食快手菜 / 冻品面点 / 酒水饮料 / 休闲零食 / 粮油调味 / 日用清洁 / 个护美妆…
- 分类页：左侧子类，上方排序（销量 / 折扣 / 价格）和条件（如「省心价」「当日鲜」）
- 商品卡：名称 + 规格（容量 × 数量）、**生产日期**、冷藏 / 严选标、价格标签（省心价 / 会员价 / 体验价 / 秒杀价）+ 划线价；「+」是加购，「抢」是秒杀加购
- 底部：推荐 / 分类 / 购物车 / 我的

## 常见任务

- **找某样东西的价格**：搜索框搜，或从品类进；对比时看**规格换算后的单价**（每 100 ml / 每 kg）而不只是标价
- **新鲜度**：生鲜、乳品看生产日期 / 「当日鲜」标，告诉用户
- **凑起送 / 免运费**：参考首页写「满 39 元 0 运费」，用户要下单时说明差多少，不替用户凑单

## 风险与坑

- 「会员价」「体验价（首件减 X）」「秒杀价」是有条件的价，按「购物通用」区分
- 浮动「领券」、「开启消息通知」：不点
- 购物车里可能已有东西（参考：角标显示 1）：不动

## 停在哪

只看的任务不加购。用户要下单：加购后最多到结算页，读出商品、数量、价格、运费、优惠、实付、地址、送达时间，截图交用户。
