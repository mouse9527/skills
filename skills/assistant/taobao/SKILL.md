# 淘宝（手机 App）

先遵守「手机通用规则」（硬规则：不下单不付款、手机任务不用浏览器、验证码最多 3 次）；比价和到手价判断按「购物通用」。这里是淘宝 App 的方向和参考，界面以当时为准。

## 适用场景

淘宝 / 天猫的商品搜索、比价、看详情和评价、看购物车；用户明确要求时加购。

## 入口与定位

- 包名 `com.taobao.taobao`，用手机服务启动
- 冷启动常有大弹窗（参考：「淘金币 · 领」），找关闭（×）关掉，**不点「领」**
- 热启动会回到上次停留的 tab（参考：上次在购物车，打开还是购物车），先确认在哪个页面
- 首页顶部有搜索框；顶部 tab 里的「闪购」是外卖，不是网购

## 怎么看界面

- **先读元素**（「手机通用规则」第 4 节）。参考 2026-10-20 mobile-mcp 实测：首页、搜索页、结果页、商品页都能读到。结果卡片 label「【官方正品】… 1472.02元 3000+人付款」，顶部还有比价条（「品牌旗舰店 1899 全国联保 / 百亿补贴 1249 / 国家补贴 1498.21 / 天猫自营 1498.6」）；商品页价格数字被拆成一位一个节点，**读父节点 label**（如「平台加补后￥1472.02优惠前￥1899」）。**购物车读不到**商品（只有底栏）——看购物车要截图
- 点了没反应：先截图看是不是还在加载 / 动画中，再点一次，不要连点

## 常见任务

- **搜索**：点首页搜索框，输入关键词提交。输入按「手机通用规则」第 6 节：关键词带中文（「苹果AirPods Pro 3」）、输完读输入框（`searchEdit`）核对；框里有旧字先点「清空搜索框中内容」。结果页通常有排序（综合 / 销量 / 天猫 / 店铺）和筛选（右侧漏斗）。要「天猫 / 官方」先用对应 tab 或筛选，比翻页快
- **店内搜索 vs 全站搜索**：进了某家店铺页之后，页面上的搜索框**只搜这家店**（参考 2026-10-20：结果页出现「没有找到更多商品，为您推荐本店其他商品」就是在店内）。要全站搜，BACK 回首页 / 全站结果页再搜；搜完读元素核对顶部关键词和范围（见「手机通用规则」第 6 节）
- **结果页读元素就够**：一次 `list_elements` 能拿到每张卡的「标题 价格 付款人数」，挑候选、比价时不必每屏截图；看商品图（规格、包装）时才截图（参考 2026-10-21 回归：只有购物车需要截图，其余页面截图 48 次多是不必要的，一次任务耗时近 10 分钟）
- **比价**：在结果页先挑出**同款**（型号、版本、规格一致）的几家，再逐个进商品页看到手价；结果页卡片上的价格是参考，以商品页为准
- **看商品页**：同屏常有多层价格（参考：「活动补贴后 ¥X（今晚 8 点开卖）」「平台加补后 ¥Y」「领取政府补贴 3%」「88VIP 价」「淘金币抵扣」），按「购物通用」区分当前价 / 条件价 / 未开始的活动价。规格在「已选」或规格区；评价在下方或「评价」入口，读几条够用就停
- **看购物车**：底部「购物车」tab。按店铺分组，每件显示规格、当前价、未来活动价、缺货提示；勾选和数量**不动**
- **返回**：从结果页按 BACK 通常先回到搜索联想页，再按一次才回首页
- **收货地址**：网购按「用户位置」skill 第 5 节 B——要加购 / 下单、或地址影响结论（运费、能不能发、国补地区）时，先读已保存地址列表问用户寄到哪个；只查价、比价时按 App 当前地址，回复里说明用的是哪个（参考：商品页「送至 <地址>」那一行，点开就是地址列表；未实测）

## 要读出的信息

商品名 + 规格、店铺（天猫 / 淘宝 / 超市、旗舰店还是普通店）、到手价及条件、销量 / 付款人数、发货地与送达（明日达等）、售后（7 天无理由、退货包运费）、评价要点。

## 风险与坑

- 搜索结果里混着广告卡（标「广告」）
- 「今晚 8 点」「双11」之类的价格是未来价，和现在能买的价格分开说
- 底栏「加入购物车」「领券购买」：前者只在用户明确要加购时点，后者不点（等于购买）
- 弹出「领红包 / 淘金币 / 开会员」：关掉，不领
- 验证码（滑块等）按「手机通用规则」处理（App 内同一验证最多 3 次）；登录失效交给用户

## 停在哪

默认看完给比价结果就停，不加购。用户要加购：加完告诉用户加了什么，**不去结算**。

## 商品链接

最终回复给商品链接按「购物通用」的「给用户商品链接」：**默认分享 → 复制链接拿 `e.tb.cn` 直达短链**，拿不到退回搜索链接并注明。淘宝这边的参考（2026-10-22 实测，界面以当时为准）：

- **分享按钮**：详情页右上角，搜索和购物车之间，元素里读得到（label「分享，按钮」）。进详情页时常先弹「获得平台加补券 / 开心收下」之类的弹层，点下面的 × 关掉（**不点「开心收下」**），再点分享
- **分享面板元素读不到**，只能截图后按坐标点。面板长这样：上方是商品卡片预览；中间一排图标 **微信 / 复制链接 / 保存图片 / QQ / 支付宝 / 当面…**（「复制链接」是**左数第 2 个**，橙色链条图标）；下面「分享给好友」列出**真实联系人**，每人右边一个「分享」按钮（**一点就发**）；最底下「取消」
  - 坐标参考（1200×2670 屏幕，以当时截图为准）：「复制链接」约 (334, 1512)；左邻「微信」x≈115，右邻「保存图片」x≈556；联系人行从 y≈1850 开始。点之前用截图核对，不要直接套这个坐标；按坐标点击（传 `x` / `y`）
- 截图核对后，**一次批量执行**：按坐标点「复制链接」→ 取前台 App（间隔）→ 读剪贴板 → BACK（**面板不会自动关**；不点联系人、不点「分享」）。第一件成功后记下点中的坐标，后面几件复用（仍先截图核对面板，见「购物通用」）
- 读到的和上一条相同 = 没复制上：重新点分享、截图核对再来（同一件最多 3 次）
- 剪贴板：`【淘宝】大促价保 https://e.tb.cn/h.<短码>?tk=<token> <口令> 「<完整标题>」 点击链接直接打开 或者 淘宝搜索直接打开`——只贴 `https://e.tb.cn/…?tk=…`
