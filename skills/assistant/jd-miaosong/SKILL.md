# 京东秒送（手机）

先遵守「手机通用规则」；外卖共性在「外卖（手机）」；价格判断在「购物通用」。这里是京东秒送的方向和参考。

## 入口与定位

- 在京东 App（`com.jingdong.app.mall`）里：首页顶部「**秒送**」tab，或首页「外卖」「自营秒送」入口——实测点「外卖」会落到秒送 tab（tab 标「秒送 · 外卖」）
- 进入后常先弹优惠券（参考：「外卖优惠券 已到账」，按钮「开心收下 / 去使用」）：点关闭（×）即可，「开心收下」是领券，不点（除非用户要求）
- 秒送页元素能读到（参考 2026-10-20 mobile-mcp：359 行，店铺卡 label「店名 评分 月售 起送 运费」、外卖券提示），先读元素

## 页面参考（2026-10-20 实测，可能改版）

- 顶部搜索框（占位词带「外卖」标），下面一行是**收货地址**
- 频道：自营秒送 / 外卖 / 超市秒送 / 咖啡奶茶 / 买药秒送 / 自提 / 午餐 / 生鲜果蔬…
- 列表排序：综合排序 / 到店自提 / 预订送达时间 / 营养等级
- 店铺卡：评分、月售、送达时间、距离、起送、配送费 / 免运费
- 底部常有「N 张外卖券待使用」

## 切收货地址（参考 2026-10-21 实测）

- 入口：秒送 / 外卖搜索结果页顶部的地址按钮（label 就是当前地址）→ 弹出「选择地址」
- 这个弹层是网页，**元素读不到，要截图**
- 结构：顶部当前地址 +「重新定位」；tab「推荐 / 购物 / 秒送 / 服务」；已保存地址列表（区、地址、标签「家 / 公司」、「上次下单」「购物默认」），每条右侧「复制 / 修改」，下面「设为购物默认」；底部「新增收货地址」
- 选择：点那条地址的文字（2026-10-21 回归里模型这样切成功，「购物默认」没变），切完回到结果页读顶部地址核对。注意「设为购物默认」就在地址文字下面一行，按截图点时别点低了
- **不点**：「设为购物默认」（改默认地址）、「修改」「复制」、「新增收货地址」、「重新定位」（用手机定位）
- 关闭：右上角 ×

## 常见任务

- **看某家店的菜单 / 配送费**：秒送页搜索框搜店名（参考：范围显示「搜秒送」，中文输入这次正常），结果卡上通常已有评分、起送、配送费、送达时间、距离和几样菜的「到手价」→ 进店读菜单（参考：店铺页是京东小程序页面，左侧分类、右侧菜品，「选套餐 / +」是加购）
- **超市秒送 / 买药**：从对应频道进，看商品、价格、送达时间
- **比价**：按「外卖（手机）」

## 风险与坑

- 首页「品质生活」块里显示的城市是 App 的城市级位置，不是用户位置；外卖按收货地址
- 外卖券、红包有门槛（满 X 可用），按「购物通用」说明，不替用户领
- 菜单上的「到手价 / 单件预估」常以「超级餐补券」之类的券为前提（参考实测：满 25 可用），和菜单价分开报
- 地址行一点就进「选择地址」页。要不要切、按什么切看「用户位置」skill 第 5 节：外卖按用户所在位置，超市秒送 / 买菜问用户送哪个；不需要切时误入了直接 BACK（参考下方「切收货地址」）
- 结果页卡片可能有「+」加购按钮，只看菜单时不点

## 停在哪

只看菜单不加购。用户要下单：最多加购到结算页，读出明细，截图交用户。
